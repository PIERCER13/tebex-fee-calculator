# calculator of fees & Ganhos — Tebex

simulate sales in FiveM/RedM (15%), Minecraft/Rust (5%), gateway and conversão for Reais

## Features

- **Tabs / Modes**: price → Líquido, how much to charge
- **Main Sections**: Divisão of sale, Divisão of cada sale, Projeção per volume of sales
- **Available Actions**: reset, PDF, copy summary, price → Líquido, how much to charge, refresh
- **Auto-Save**: automatically persists changes in the browser (`localStorage`).
- **Multi-Language**: built-in language switcher (`PT / EN / ES`).
- **Print / PDF**: A4-optimized print layout via `@media print`.

## How to Run

1. Run `start.bat` to start the local server on port `8095`, or open `index.html` directly in your browser.
2. Open `http://localhost:8095`.
