# Calculadora de Taxas & Ganhos — Tebex

Simule vendas em FiveM/RedM (15%), Minecraft/Rust (5%), gateway e conversão para Reais

## Funcionalidades

- **Abas / Modos**: Preço → Líquido, Quanto Cobrar
- **Seções principais**: Divisão da Venda, Divisão de cada Venda, Projeção por Volume de Vendas
- **Ações disponíveis**: Resetar, PDF, Copiar resumo, Preço → Líquido, Quanto Cobrar, Atualizar
- **Persistência automática**: salva alterações automaticamente no navegador (`localStorage`).
- **Multilíngue**: suporte integrado com botão de troca de idioma (`PT / EN / ES`).
- **Impressão / PDF**: layout otimizado em folha A4 via `@media print`.

## Como Executar

1. Execute `start.bat` para iniciar o servidor local na porta `8095`, ou abra `index.html` diretamente no navegador.
2. Acesse `http://localhost:8095`.
